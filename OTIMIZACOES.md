## Melhorias de Conversão

### Fase 1: Quick Wins (1-2 semanas)

#### 1. Adicionar Formulários de Captura
- **B2B**: Formulário de diagnóstico em 3 etapas
  - Etapa 1: Dados da empresa (nome, cargo, empresa, setor)
  - Etapa 2: Desafio principal (múltipla escolha)
  - Etapa 3: Contato e melhor horário

- **B2C**: Formulário de aplicação em 4 etapas
  - Etapa 1: Dados pessoais (nome, cargo atual)
  - Etapa 2: Situação profissional (múltipla escolha)
  - Etapa 3: Objetivo de carreira (texto curto)
  - Etapa 4: Contato e disponibilidade

#### 2. Implementar Exit-Intent Popups
- **B2B**: "Antes de sair, baixe nosso Checklist de Transformação Ágil"
- **B2C**: "Descubra em 2 minutos qual o seu maior bloqueio de carreira"

#### 3. Adicionar Chat ao Vivo
- Horário de atendimento: Segunda a sexta, 9h-18h
- Qualificação automática:
  - "Você é empresa ou profissional?"
  - Direcionamento para página correta
- Fora do horário: Formulário de contato

#### 4. Criar Páginas de Obrigado
- `/consultoria/obrigado`: Confirmação de agendamento + próximos passos
- `/mentoria/obrigado`: Confirmação de aplicação + o que esperar

## Otimizações Técnicas

### SEO Avançado

#### 1. Schema Markup
Implementar structured data:
```json
{
  "@context": "https://schema.org",
  "@type": "Person",
  "name": "Ronara Lamounier",
  "jobTitle": "Consultora de Transformação Ágil",
  "url": "https://ronaralamounier.com.br",
  "sameAs": [
    "https://linkedin.com/in/ronaralamounier",
    "https://instagram.com/ronaraconsultora"
  ]
}
```

#### 2. Sitemap Dinâmico
Gerar automaticamente incluindo:
- Todas as páginas principais
- Artigos do blog (quando implementado)
- Última modificação de cada página

#### 3. Otimização de Imagens
- Usar formato WebP com fallback para JPEG
- Lazy loading para imagens abaixo da dobra
- Comprimir todas as imagens (target: <100KB)
- Alt tags descritivos para acessibilidade e SEO
